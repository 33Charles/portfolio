# Blue Teaming Notes

This section focuses on defensive security practices and the techniques used to detect, analyze, and respond to malicious activity.

The notes cover areas such as log analysis, threat detection, incident response, and monitoring systems using security tools. Many entries are based on hands-on labs and experiments involving system logs, network traffic, and security monitoring platforms.

The goal is to better understand how attacks are detected and how defenders can improve visibility and response to security incidents.
