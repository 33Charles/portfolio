Next i proceeded to extract the binary for analysis.

Uploading the binary to virustotal i get this 

![[Pasted image 20251007112255.png]]


It is a Havoc trojan. Havoc is a C2 framework, https://github.com/HavocFramework/Havoc

Research on how to analyze network traffic generated by havoc i get this.

https://www.immersivelabs.com/resources/blog/havoc-c2-framework-a-defensive-operators-guide

From the above post we identify essential information about havoc:

-  The C2 framework uses AES and IV keys for encryption using **`CTR`** mode which can be extracted from network traffic. Since we have the network traffic we have the keys in our hand which we can use for decryption.

-  The C2 framwork also uses the magic byte of `**0xDEADBEEF**`

Searching the magic byte in our network traffic i locate it at multiple post requests.

![[Pasted image 20251007114827.png]]

> [!Info]
> CTR (Counter) mode turns AES-256 into a stream cipher by encrypting a sequence of counter blocks (derived from the IV/nonce) with the AES key to produce a keystream which is then XORed with the plaintext to produce ciphertext; decryption is identical — generate the same keystream and XOR with ciphertext to recover plaintext. CTR requires no padding, allows parallel/random-access encryption and decryption, and depends critically on using a unique IV/nonce for every encryption with the same key (reusing an IV leaks keystream and permits plaintext recovery).

The researcher also provide a python tool for decrypting havoc traffic 

https://github.com/Immersive-Labs-Sec/HavocC2-Forensics
