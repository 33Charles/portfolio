# Red Teaming Notes

This section contains notes related to offensive security and penetration testing. It focuses on techniques used to identify, exploit, and demonstrate vulnerabilities in systems and applications.

Topics documented here include web exploitation, privilege escalation, Active Directory attacks, reverse engineering, and vulnerability discovery. Many notes are derived from hands-on labs, capture-the-flag challenges, and practical exercises.

The purpose of these notes is to document learning progress, record methodologies, and build a reference for offensive security techniques.
